# peekeep — Cushy와 함께 내 속도로 피드백 확인하기

공감각적경험디자인 5팀의 2026-10-24 Figma 프로젝트(페이지 1024)에 기반한 **모바일 중심 인터랙티브 콘셉트 프로토타입**입니다.

**서비스 이름:** peekeep (픽킵)  
**캐릭터 이름:** Cushy (쿠션 메타포)

## 체험하기
https://kbg0705.github.io/creator-feedback-prototype/

첫 방문에는 온보딩이 표시됩니다. 다시 체험하려면 상단 '처음부터'를 누르세요. PC에서도 모바일 프레임으로 표시됩니다.

## 화면 흐름
1. Cushy 소개 → SNS 선택 → 피드백 수용 성향 질문 → 쿠션 강도 설정
2. **반응 공간**: 콘텐츠별 반응 및 반응 날씨
3. **반응 브리핑**: 원문 대신 질문·응원·비판·공격 유형별 요약
4. **중요 피드백**: 질문과 건설적 의견을 우선 확인
5. **PEEK**: 공격적 표현의 사전 경고 → 사용자가 직접 원문 열람 여부 선택 → 다시 가리기
6. **KEEP**: 의미 있는 피드백을 개선할 일로 보관
7. **MY PEEK**: 쿠션 강도 및 알림 선호 변경

## 구현 범위와 한계
정적 HTML/CSS/JavaScript 기반 사용자 흐름 시뮬레이션입니다. 실제 SNS 연동, 댓글 실시간 수집 및 AI 판단 기능은 없습니다. 캐릭터는 원본 이미지의 직접 복제가 아닌 임시 CSS 시각화입니다. Figma의 아이디어 스케치가 완성된 제품 UI 사양은 아니므로 컬러·그래픽 및 상호작용은 이후 검토가 필요합니다.

## 연구 기반
- 사전 보호
- 중요한 피드백에 대한 접근성
- 노출 시점과 범위에 대한 사용자 선택 및 통제감
