# 온도 · Creator Feedback Prototype

**1인 크리에이터의 피드백 노출과 통제 경험**을 탐색하는 모바일 우선 인터랙티브 프로토타입입니다.

공감각적경험디자인 5팀의 2026-10-24 리서치 방향을 참고한 초기 콘셉트이며 최종 검증된 서비스가 아닙니다.

## 실행
GitHub Pages 배포 후 https://kbg0705.github.io/creator-feedback-prototype/ 에서 실행합니다. 배포 전에는 `index.html`을 브라우저로 열어 체험할 수 있습니다.

## 체험 흐름
- 홈 → 중요한 피드백 확인 → 보호된 댓글 직접 열람/다시 가리기
- 홈 → 게시 전 보호 설정 → 완료
- 설정 → 댓글 가리기/중요 알림/조용한 시간 조절

## 디자인 원칙
1. **사전 보호**: 게시 전에 피드백 노출 방식을 선택
2. **중요 피드백 접근성**: 질문·제안·협업 문의 우선 접근
3. **사용자 선택·통제감**: 가려진 댓글을 언제든 열람하고 설정 변경

## 주의사항
가상 데이터로 화면을 체험하는 정적 프로토타입입니다. 실제 SNS API, 댓글 수집, AI 분류, 계정 연동 또는 사용자 데이터 저장은 포함되지 않습니다. 연구 결과의 정량 수치는 일반화할 수 없습니다.

## 배포 방법
Repository **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**.
